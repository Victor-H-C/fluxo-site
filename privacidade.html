Política de Privacidade

Última atualização: 6 de outubro de 2026.

Esta política descreve como o aplicativo Fluxo (Windows e Android) trata as informações do usuário.

Dados que o Fluxo guarda

Os lançamentos financeiros, tags, cartões e configurações que você cadastra ficam salvos em um arquivo no seu próprio aparelho. O Fluxo não possui servidores: nenhum dado é enviado ao desenvolvedor nem a terceiros.

Integração com o Google Drive

A sincronização com o Google Drive é opcional. Ao conectar sua conta Google, o Fluxo solicita apenas o escopo https://www.googleapis.com/auth/drive.file, que permite acessar somente os arquivos criados pelo próprio aplicativo. O Fluxo cria uma pasta chamada Fluxo com o arquivo dados.json no seu Drive e usa esse arquivo exclusivamente para guardar e sincronizar os seus dados entre os seus aparelhos. O Fluxo não lê, altera nem lista nenhum outro arquivo do seu Drive.

O Fluxo também consulta o endereço de e-mail da conta conectada apenas para exibi-lo na tela do aplicativo.

A comunicação acontece diretamente entre o seu aparelho e os serviços do Google. As credenciais de acesso ficam armazenadas somente no seu aparelho. Você pode desconectar a qualquer momento pelo menu do aplicativo ou em myaccount.google.com/permissions. Desconectar não apaga o arquivo do seu Drive; você pode excluí-lo manualmente quando quiser.

Uso limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados obtidos pelas APIs do Google não são vendidos, não são usados para publicidade e não são compartilhados com ninguém.

Exclusão de dados

Desinstalar o aplicativo remove os dados do aparelho. Os dados no Google Drive podem ser apagados excluindo a pasta Fluxo.
